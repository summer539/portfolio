# 集团格式合同审核——条款核对清单

> 适用对象：采用某化工集团标准模板签订的合同（框架合同、子合同、非框架合同模板）
>
> 审核核心：**两步校验**——①完整性校验：条款**不允许缺失、不允许修改**；②待填项逐一审查：对照待填项清单**每个待填项都要审查**
>
> 版本同步：本清单已同步《采购合同审核SOP》V2.6（V2.4优化项【优化同步】+客户修改版V2.5同步+9项夹注反馈V2.6落版）；验收/收款时长等数值为参考值，可按公司管理要求个性化配置；账期在60日合规线内按供方授信确定；境外合规表述待公司标准模板确认。
>
> **2026-09-04 实战经验固化（塑封套框架主/子合同案例）：** ①模板固定文本不批注（第二步说明）；②价税勾稽按税率倒算双向验证＋大写规范汉字（通用核对项四）；③履行期倒签/逾期检查（通用核对项四）；④子合同单价与母合同价目单逐项比对、规格须区分到位（3.3明细表）；⑤子合同与母合同关联核验流程（3.3固定核对值）。详见正文标注。

## 一、审核逻辑（两步流程）

集团格式合同已由某化工集团法务拟定标准条款，需方保护性条款齐备。供方使用该模板签约时，主要风险是**删减、漏填、弱化条款**。

### 第一步：完整性校验（不看所有待填项）

**不看任何待填项**（忽略 sdt 内容控件、横线、空格等填写值），仅比对**条款结构与条款文本**：

- 条款是否**存在**（未被删除）——对照模板原件（法务定稿）逐条核对，**不允许缺失**
- 条款内容是否**完整**（未被截断、修改、弱化）——逐款比对原文，**不允许修改**
- 发现缺失或修改 → 一律判**高风险**（类型：条款缺失/条款弱化），须恢复模板原文

### 第二步：待填项逐一审查（每个待填项都要审查）

按业态对照**待填项清单**（第三章，已整合），**逐项核对、一项不漏**：

- 非框架（普通）合同 → 第三章 3.1（46项）
- 框架合同 → 第三章 3.2（约73项，**含附件一子合同样式34处空白，易漏重点**）
- 子合同 → 第三章 3.3（34项，**含签署栏4处无占位符空白**）

每项审查两件事：①**是否填写**（空白/"/"占位=问题）；②**填写是否正确**（按SOP规则：金额勾稽、付款≤60日、承兑注期限、计量单位不得空白等）。

> 清单外发现任何空白填写处 → 视为模板外新增空白，须确认原因。
>
> **模板固定文本不批注（2026-09-04 实战固化）：** 完整性校验确认**未被删改**的集团模板固化条款（如集量/框架模板违约金"每日1%、上限30%"）属集团法务定稿文本——**不按待填项审查、不评判数值高低、不批注**；违约金等比例类审查仅针对**待填空白项**的实际填写值。避免把模板自带条款误报为风险。

### （四）价款、付款与合规通用核对项【优化同步·V2.4】

|--------|------|

| 背靠背付款 | 不得以"需方收到下游回款"为付款前提，发现即退回修改 |
| 质保金（如有） | 预留合同总价5%-10%，质保期满无质量问题后无息支付 |
| 预付款（如有） | 不超过合同总价10%-30%，大额采购须等额预付款保函/履约保函 |
| 履约保证金（如有） | 不超过30%，明确付款时间/退还条件/退还时间，专户独立于甲乙双方 |

### （五）质量、验收与安全通用核对项【优化同步·V2.4】

> 三业态模板共性条款的审查建议（模板条款存在性由第一步完整性校验对照模板原件核对，此处为填写值与商务审查要点）。

| 核对项 | 要求 |
|--------|------|
| 三包期限 | 双轨表述（安装调试合格之日起12个月或到货验收合格之日起18个月，先到期为准）为集团通行惯例，**正常审核不作为风险误报**（V2.6业务确认：实务基本不存在缩短质保期）；仅异常短（单轨不足12个月、起算点早于到货验收）才提示；时长可按公司管理要求个性化配置 |
| 质保期重新起算 | 质保期内标的出现质量问题须约定解决方案；问题解决后质保期重新起算**降级为谈判争取项**（V2.6业务确认：实务难执行、供应商一般不响应，频繁修复在供应商评价中体现） |
| 质保期外追责 | 隐蔽瑕疵、内在质量问题在质保期外发现的，供方仍需承担退换、维修、赔偿责任【优化同步】 |
| 验收异议期（参考值） | 到货后15个工作日（表面检验）；异议时间、方式明确；时长（15/30日）可按公司管理要求个性化配置【优化同步·批注】 |
| 验收主动权 | 验收依据明确（书面验收确认单）；验收主动权在需方，不接受任何"视为合格"约定（含"逾期未验收视为合格"）【优化同步】 |
| 人身及财产安全 | 供方人员造成我方或第三方人身、财产损害的，应承担赔偿责任【优化同步】 |

## 四、批注输出格式

```
【风险等级·类型】问题摘要 → 修改建议
```

- 风险等级：高 / 中 / 低
- 类型：条款缺失 / 条款弱化 / 信息空白 / 价格异常 / 付款不明 / 签署空白
- 示例：`【高·条款缺失】第七条第5款压力管道元件三证条款被删除 → 恢复原条款`
- 示例：`【低·信息空白】项目号留空 → 补全项目号`
- 一条批注只说一个问题，多个问题分开写
- **空白项锚定规则**：批注锚点定位在**空白填写处本身**（空白sdt/空白单元格），**不得锚定表头或标签文字**（如"计量单位"空白批注锚定其空白单元格，不锚定"计量单位"表头）

```

完整性校验（条款不许缺失/修改）：通过 X 项，存疑 Y 项，不通过 Z 项
条款缺失/修改：列出被删减或改动的条款（高风险）
待填项审查：共 N 项待填项，已填 M 项，空白/异常 K 项
填空项空白：列出未填写的填空项
总体结论：可签署 / 修改后签署 / 存在重大风险不建议签署
```
