## 一、unified_search_service（统一搜索服务）

### 用途
查询签约主体的履约能力相关信息：
- 涉诉信息
- 失信被执行记录
- 经营异常
- 行政处罚

### 使用场景
审核非政府机构签约主体时，**必须使用**此服务查询其履约能力。

### 接口信息
- **地址：** `GET http://<内部服务地址>/api/search`
- **参数：** `query`（字符串，必填）— 简明搜索关键词
- **返回：** JSON格式的事实数据和来源

### 调用示例
```bash
curl -G "http://<内部服务地址>/api/search" --data-urlencode "query=某设备公司 涉诉 失信"
```

## 二、Word文档处理系统

### 依赖环境
- python-docx（已安装 1.2.0）
- docx-comments（已安装 0.3.0）
- lxml（已安装 6.1.0）

### 脚本工具
| 脚本 | 功能 | 适用场景 |
|------|------|---------|
| `scripts/revision_edit.py` | 修订标记修改+批注 | 首推方式，直接改原文 |
| `scripts/add_comments.py` | 仅添加批注 | 备选，不改原文 |

### 转换工具
- LibreOffice（已安装）用于 doc ↔ docx 格式转换
