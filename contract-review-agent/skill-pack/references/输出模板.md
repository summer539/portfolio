# 审核输出模板

> 定义合同审核结果的各种输出格式和规范。

---

## 一、Word文档修订版（首推方式）

使用 `scripts/revision_edit.py` 在原文上直接做修订标记修改。

**格式规范：**
- **作者署名：** 小龙(合同审核助手)
- **删除标记：** 🔴 红色删除线（原条款）
- **新增标记：** 🔴 红色下划线（修订后内容）
- **批注（Comments）：** 每条修改附批注说明原因和谈判建议
- **格式保留：** 原文档的字体、字号、加粗、颜色、对齐等排版格式**必须完整保留**

**示例批注格式：**
```
🔴【争议管辖】原条款约定在乙方所在地（上海）诉讼，对甲方极为不利。已修订为甲方所在地法院，大幅降低维权成本。
```

**严重级别前缀：**
| 前缀 | 含义 |
|------|------|
| 🔴 | 高风险 — 必须修改 |
| 🟡 | 建议项 — 建议优化 |
| ℹ️ | 提示 — 信息参考 |
| ✅ | 合规 — 条款符合标准 |

---

## 二、Word文档批注版（备选方式）

使用 `scripts/add_comments.py` 仅添加批注，不修改原文。

适用场景：用户只需要批注意见，不需要直接改合同文本时。

---

## 三、结构化审核报告（文本/非Word格式）

当合同为文本格式或用户要求报告形式时使用。

```
## 📋 审核摘要
（整体评价，1-2句话）

## 🔴 高风险项
| # | 条款 | 问题 | 建议 |
|---|------|------|------|
| 1 | §X | ... | ... |

## 🟡 建议项
| # | 条款 | 问题 | 建议 |
|---|------|------|------|

## ℹ️ 提示项
...

## ✅ 合规项
...

## 📊 优先谈判清单
1. **最重要** — ...
2. **次重要** — ...
3. **可协商** — ...
```

