# 项目作品集

三个 AI 应用落地项目：把客户的业务流程拆成可执行的规则与工具，做成能被智能体直接调用的技能包，并与真实业务数据完成验证。

> 为保护客户信息，仓库中的客户名称、组织架构、联系方式与对接凭证均已脱敏或替换为占位符。

---

## [制度智能审核（某通信基础设施央企）](./policy-compliance-review)

面向企业制度的合规审核。自建含 **3,837 部法规、约 10.4 万条条款**的本地法规库（SQLite FTS5），按条款级检索定位审核依据，输出逐条问题清单，并生成带修订标记的文档。同类文件符合性审核由约 **11–15 分钟缩短至约 3–5 分钟**。

目录内容：

- 业务架构图、法规库字段与版本设计、需求拆解概览
- 法规检索演示页（可直接打开）
- 修订对比阅读器：完整源码、示例文档、界面截图
- 审核技能包：法规检索、制度审核、完整性审核、一致性审核、修订批注 共 5 个技能

---

## [合同审核（某化工集团）](./contract-review-agent)

面向采购合同的初审。**先判立场、再判业态**，分三条轨道走不同的审核标准；批注只标高风险问题并精确锚定到原文，人工确认后才生成修订版文档。

目录内容：

- 三套分轨审核标准：集团模板条款核对（含三类模板的待填项全量清单）／非模板采购合同 SOP／销售合同审批 SOP
- 批注输出规范：双通道、类别词表、锚点规则
- 工具脚本：docx 全文提取（含 Word 内容控件）、精准批注、修订标记、印章检测、PaddleOCR 识别

---

## [智能排产与经营日报（某陶瓷制造企业）](./production-scheduling)

打通金蝶云星空 ERP 取数，把人工排产经验固化成裁决算法；另有一套独立的日报技能，每天自动产出产销率与回款率播报。

目录内容：

- 排产技能：路由器 + 4 个子技能（数据拉取／双基地排产／Excel 输出）+ 裁决引擎
- 逻辑方案、规则参数表、输出格式设计
- ERP 数据资产清单，以及取数与口径的纠错记录
- 日报技能：库存快照、邮箱日报、企微晨报三个脚本与配套模板
