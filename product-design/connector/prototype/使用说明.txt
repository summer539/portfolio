Claworks 桌面端 UI 改版原型 — 离线展示包
===========================================

打开方式（任选其一）：
1. 直接双击 index.html，用 Chrome / Edge 打开即可（推荐，无需安装任何环境）
2. 或启动本地静态服务后访问，例如：
   - Windows:  在文件夹地址栏输入 cmd 回车，执行  python -m http.server 8000
               然后浏览器打开 http://localhost:8000/
   - macOS:    终端 cd 到本文件夹，执行  python3 -m http.server 8000
               然后浏览器打开 http://localhost:8000/

说明：
- 纯前端原型，全部数据为内置演示数据，不联网、不写文件
- 已包含：新建任务 / 智能体 / 技能 / 定时任务 / 连接器 / IM 频道 / 设置 等全部页面
- 连接器演示入口：左侧边栏【连接器】，或新建任务输入框左侧【连接】
- 演示建议：连接配置弹窗内有「模拟超时」按钮，可快速演示授权超时状态
