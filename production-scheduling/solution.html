V6 裁决算法

不是拍一个数，而是让三个时间维度互相校验

缺口计算

短期缺口与加权缺口取大值，避免被单日波动带偏

# 三层日均
d7  = s_cycle / 7
d30 = s_30d   / 30
d90 = s_90d   / 90

# 双缺口取大
gap7 = max(0, s_cycle − inventory)
d_w  = 0.5·d7 + 0.3·d30 + 0.2·d90
gap_w = max(0, d_w × 7 − inventory)
gap  = max(gap7, gap_w)

# 边界与取整
P ≤ d90 × 60 天
P ≤ 日产能（箱）
P = round(P / 500) × 500

趋势判定

三级梯度法：看 7 天有没有真放量，而不是被一天的数据骗

🔥加速上涨d7 > d30 > d90×1.2
📈回暖上涨d7 > d30 ≈ d90
➡️平稳三者接近
📉降温d7 < d30×0.7
⬇️持续衰减d7 < d30 < d90
⚡脉冲波动>2× 或 <0.3×
加速上涨 · 多备 3 天 回暖上涨 · 多备 1 天 脉冲波动 · 屏蔽 7 天 衰减 · 压至起排量
