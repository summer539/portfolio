## 交付物说明

[`skill-pack/`](./skill-pack) 是项目的核心交付物，由两个独立技能组成：

### 智能排产（prod-schedule）

采用「路由器 + 子技能」结构：主技能只做调度，四个子技能分别负责数据拉取、A 基地排产、B 基地排产和 Excel 输出。

最关键的设计判断是**营销计划表只用来确定「排哪些产品」**——数量由 AI 拿着产品清单去 ERP 查库存与销量，跑裁决算法自己算出来，最后与营销建议并排对照展示。裁决引擎按多时间维度计算缺口，包含三日均与趋势判定、双缺口、趋势加成与安全阀。

### 每日经营日报（daily-report）

每天三个定时任务串成闭环：23:59 抓库存快照 → 08:30 发邮箱 HTML 日报（含 CSV 附件）→ 09:00 发企业微信晨报。核心指标是产销率（用库存快照反推产量，不依赖生产订单模块）、月累计回款率、断货／积压预警和 TOP5 畅销。

两个技能共用同一套 ERP 取数底座，但不共享代码，可以分别部署。

详见 [`skill-pack/README.md`](./skill-pack/README.md)。
