# 参数计算规则（daily-report 技能）

> 用户确认口径（2026-08-12/13），**永久规范**，改动任何一条需客户/用户人工确认。

## 0. 统一数据口径（所有指标共用）

1. **等级**：优等品 = 优等(FAuxPropID=100001) + 优AA(100009)，两者都算
2. **组织**：仅 某陶瓷企业生产基地(100080) + B 基地生产基地(100082)
3. **仓库**：仅 成品一仓(119400) + 成品三仓(177653)
4. **排除客户**：某销售中心、某陶瓷有限公司（内部/关联单，整单排除；**回款统计同样排除**，否则回款率虚高）
5. **赠品**：FIsFree=True（ERP官方标识），赠品金额恒为0，**计入出库量**但单独标注 free_qty、不计销售额

## 1. 昨日销量 / 销售额

```
查询：SAL_OUTSTOCK
过滤：FDate = 统计日(昨天) AND FStockOrgID IN (100080,100082)
      AND FAuxPropID IN (100001,100009) AND FStockId IN (119400,177653)
      （Python端再排除 INTERNAL_CUSTOMERS 的整单）
聚合：FRealQty（实际出库数量，注意不是 FQty！）→ 销量(箱)
      FAllAmount → 销售额(元)
赠品：FIsFree=True 的行数量计入出库量、金额恒为0
```

## 2. 昨日产量（快照反推，路径B）

```
产量(单产品) = 昨日末库存快照 − 前日末库存快照 + 昨日出库量
只保留 产量 > 0 的产品（忽略杂项出入库，口径标注）
整体产量 = Σ 各产品产量
```

- 快照来源：每日23:59 `daily_stock_snapshot.py` 拉取 STK_Inventory 全量（仅优等品，**含0库存行**）
- 快照缺失（缺统计日或前一日）→ 降级：产销率/库存/预警部分显示"快照不足"，其余照常

## 3. 产销率

```
产销率(单产品) = 产量 ÷ 销量 × 100     （无销量 → 显示"—"）
整体产销率    = Σ产量 ÷ Σ销量 × 100
状态标注：
  <90%           → 消化库存（绿 #67C23A）
  90% ~ 110%     → 产销平衡（蓝 #409EFF）
  >110%          → 库存累积（黄 #E6A23C）
```

## 4. 回款率（月累计口径，销售出库回款率·业务指标）

> 业务口径（2026-08-14 用户确认升级）：业务部门/生产运营考核用，非财务准则指标——业务更关心"发给客户的货收回多少资金"。分子用收款单实际回款 FRECTOTALAMOUNTFOR，分母用销售出库单**已审核**出库金额。

```
分子：本月收款 = AR_RECEIVEBILL.FRECTOTALAMOUNTFOR（分录行金额）
      查询必须带 FBillNo（触发分录行返回），行级金额汇总 = 单据总额（不重复）
      过滤：FDate ∈ [当月1日, 统计日]，排除 INTERNAL_CUSTOMERS
分母：本月销售额 = SAL_OUTSTOCK.FAllAmount
      过滤：FDate ∈ [当月1日, 统计日] + FDOCUMENTSTATUS='C'（仅已审核）
            + 统一口径(等级/组织/仓库/排除客户)
回款率 = 本月收款 ÷ 本月销售额 × 100
```

- **收款查询字段**：FBillNo（单据号，触发分录行返回）、FDATE（收款日期）、FCONTACTUNIT.FName（客户）、FRECTOTALAMOUNTFOR（分录行金额·本位币）
- **字段说明**：FRECTOTALAMOUNTFOR=分录行金额（同一单据多行时拆分，行合计=整单金额）；FRECAMOUNTFOR=单据头金额（多行单据每行重复整单金额，若查询不带FBillNo按单据一行返回则两者汇总结果一致）
- 收款流水每笔一行输出到 `回款流水-{month}.csv`（列：收款日期/客户/收款金额/单据号）
- 8月实测（8/1~8/13）：49,262,063.23 ÷ 34,499,919.20 = 142.8%（>100%属正常：分子含预收款+跨期回款）
- ✅ 单据状态已过滤：分母 FDOCUMENTSTATUS='C'（2026-08-14 用户确认，启用后全状态34,521,678.20→已审核34,499,919.20，差21,759元=4行未审核单）；分子本月收款单均已审核，无差异

## 5. 库存天数（可撑天数）

```
日均出库(近30天) = 该产品近30天出库总量 ÷ 30
可撑天数 = 当前库存 ÷ 日均出库
```

- 当前库存 = 统计日快照两仓合计（仅优等品）
- 日均出库为0但有库存 → 显示"—"

## 6. 环比前日

```
数量环比 = (昨日出库 − 前日出库) ÷ 前日出库 × 100
金额环比 = (昨日销售额 − 前日销售额) ÷ 前日销售额 × 100
```

## 7. 预警规则

| 预警 | 条件 | 排序/展示 |
|------|------|-----------|
| 🔴 断货预警 | 统计日在销（出库>0）且 库存 < 500箱 | 按昨日销量降序，列前4个 |
| 🟠 积压预警 | 库存 ≥ 3000箱 且 近30天零出库 | 按库存降序，列前2个；>2个时附合计 |

## 8. 阈值常量（config.py 集中管理）

| 常量 | 值 | 用途 |
|------|-----|------|
| RATE_HIGH | 110.0 | 产销率>110% 库存累积 |
| RATE_LOW | 90.0 | 产销率<90% 消化库存 |
| STOCKOUT_THRESHOLD | 500 | 断货预警库存下限（箱） |
| OVERSTOCK_QTY | 3000 | 积压预警库存上限（箱） |
| TOP_N | 5 | 畅销产品数 |
| DAYS_30 | 30 | 日均出库分母 |

## 9. 展示顺序（模板固定）

- **企微晨报**：标题/口径 → 🏭产销率 → 📊经营概况 → 📈TOP5 → 💰回款率 → ⚠预警
- **邮箱日报**：① 产销率（核心，最前）→ ② 昨日经营概况 → ③ 回款率（月累计）
- 产销率永远在回款率之前（核心指标优先）
