**输出：** `/tmp/schedule-a-result.json`

## 操作步骤

### 1. 读取数据
```python
import json
with open('/tmp/schedule-data.json', 'r') as f:
    data = json.load(f)

# 优先按base字段，缺失时回退到编码前缀MAT%
a_products = [p for p in data['products'] if p.get('base') == '某陶瓷企业']
if not a_products:
    # 容错回退：base字段可能未设置
    a_products = [p for p in data['products'] if not p.get('base') and (p['code'].startswith('MAT') or not p['code'].startswith('b'))]
    if a_products:
        print("⚠️ base字段缺失，回退到编码前缀判定")
```

### 2. 规则校核

**参考 shared references/rules.md**

#### 2.1 最低起排量校验
- 所有产品（含定制）≥1500箱
- 新品≥3000箱（备注含"新品"）
- 违规输出：品牌+编号+原因

#### 2.2 淡季策略（6/7/8月）
- 标记销量占比<5%的产品，提示可暂缓（仅供参考，不限产能）

#### 2.3 焕白(-HB)产品处理
- 排产时使用**总库存（焕白+普通）**，不单独区分
- 切换节点（仅参考）：800×800→4月25日 / 600×1200→5月7日 / 750×1500→6月13日 / 400×800→6月28日
- -HB产品库存已在 data-fetch 阶段合并

### 2.5 产能预评估
- 总排产 vs 7天产能上限

**输出：** 违规统计+前8条具体违规（品牌+编号+原因）

### 3. V6 多时间维度耦合缺口裁决

**核心理念：7天算缺口底线 → 30天验趋势真伪 → 90天设边界安全阀**

#### 3.1 三日均计算

```
d7  = s_cycle / 7
d30 = s_30d  / 30
d90 = s_90d  / 90
```

其中：
- `s_cycle/d7_sum`、`s_30d`、`s_90d` 来自 data.json
- `inventory` = `erp_stock`（data-fetch已合并焕白库存）

#### 3.2 趋势判定（三级梯度法）

| 状态 | 条件 | 图标 |
|------|------|:--:|
| 加速上涨 | d7 > d30 > d90×1.2 | 🔥 |
| 回暖上涨 | d7 > d30 ≈ d90（偏差<20%） | 📈 |
| 平稳 | d7 ≈ d30 ≈ d90（各偏差<20%） | ➡️ |
| 降温 | d7 < d30×0.7 且 d30≈d90 | 📉 |
| 持续衰减 | d7 < d30 < d90 | ⬇️ |
| 脉冲波动 | d7 > d30×2.0 或 d7 < d30×0.3 | ⚡ |

#### 3.3 双缺口取大

```
gap_7        = max(0, s_cycle − inventory)
d_weighted   = 0.5×d7 + 0.3×d30 + 0.2×d90    （d90为0时：0.6×d7 + 0.4×d30）
gap_weighted = max(0, d_weighted × 7 − inventory)
effective_gap = max(gap_7, gap_weighted)

脉冲波动⚡时：以30天为准，屏蔽7天异常数据
  effective_gap = max(0, d30 × 7 − inventory)
```

#### 3.4 趋势加成（批次档位跳）

```
effective_gap > 0 时：
  base_P = ceil(effective_gap) 上取至最近批次档位
  加速上涨🔥:   max(base_P, d_weighted×10−inventory)   ← 多备约3天
  回暖上涨📈:   max(base_P, d_weighted×8−inventory)    ← 多备约1天
  平稳➡️:       不变
  降温📉/衰减⬇️: 以 d30×7 为准，不低于 MIN_BATCH
  脉冲波动⚡:   以 d30×7 为准

effective_gap = 0（库存充足）时：
  趋势差(📉/⬇️) 且 库存偏高 → 压至 MIN_BATCH 或 d30×3（取大）
  趋势好(🔥/📈) → base_P 不变
  新品无历史 → base_P = NEW_MIN(3000)
```

#### 3.5 安全阀 + 硬约束

```
90天上限:  P ≤ d90 × 60天
上穿校正:  d30 > d90 且 P偏低 → 上修到 ceil(d30×7−inventory)
产能上限:  P ≤ 窑炉日产能(箱)（满产）
最低批次:  所有产品≥1500，新品≥3000
批次取整:  P = round(P / 500) × 500（≥500）
```

#### 3.6 裁决输出

**裁决只基于ERP数据和V6算法，不参照营销计划。plan_qty 仅用于Excel中并排对照。**

| 场景 | 裁决 |
|------|------|
| effective_gap>0 | ⚠️ 库存缺口P箱，建议排产P箱 |
| effective_gap=0 库存适中 | ✅ 批准（库存充足） |
| effective_gap=0 趋势好(🔥/📈) | ✅ 批准（趋势支撑） |
| effective_gap=0 趋势差(📉/⬇️) 库存偏高 | 📉 建议压至 MIN_BATCH 或 d30×3（取大） |
| 新品无历史 | ✅ 首排3000箱（满足最低起排） |

#### 3.8 风险标记

| 条件 | 标记 |
|------|------|
| 库存=0 且日均>5 | 🚨告急 |
| 库存天数<3 且日均>0 | 🚨告急 |
| 库存天数<10 | 🔥偏低 |
| 库存>60天 且 >500箱 或 日均=0有库存 | ⛔积压 |
| 趋势⬇️持续衰减 且 日均>5 | 📉骤降 |
| 趋势🔥加速上涨 且 日均>20 | 📈激增 |

> **库存天数上限**：日均d30=0时 inventory_days=None，标记为 ⛔积压（有库存时）。日均>0但天数>90时，统一标记为 ⛔积压，不写具体天数。**禁止展示"可撑999天"等超长天数。**

#### 3.9 优先级评分

```
优先级 = 0.4 × 库存紧迫度 + 0.3 × 客户等级 + 0.2 × 销量趋势 + 0.1 × 特殊标记
库存紧迫度 = 1 / (库存天数 + 1)
客户等级   = 定制产品=1.0, 普通=0.5
销量趋势   = min(2.0, d30/max(d90,1)) / 2.0
特殊标记   = 定制=0.5, 新品=0.5, 普通=0
```

#### 3.10 必须展示 Top3 完整计算链路

选优先级最高的3个产品，展示完整计算过程：
```
{编号} {品牌}
  d7/d30/d90 = {值1}/{值2}/{值3} → 趋势{判定}({图标})
  s_cycle={X}, inv={Y} → gap_7={Z}, d_weighted={W} → gap_w={V}
  effective_gap={E}（{取法说明}）
  base_P={A} → 趋势加成 → P={B} → 约束 → 最终P={C}
  库存天数={D}天 → {风险标记（如有）}
  裁决：{裁决结果}
```

### 4. 参数一览

| 参数 | 值 | 说明 |
|:--|:--:|:--|
| 加权日均权重 | 0.5/0.3/0.2 | 7天/30天/90天 |
| 加速上涨备货 | d_weighted×10−inv | ≈多备3天 |
| 回暖上涨备货 | d_weighted×8−inv | ≈多备1天 |
| 90天上限 | d90×60天 | 不超过两月备货量 |
| 最低批次 | 1500(所有产品) / 3000(新品) | 起排量 |
| 批次粒度 | 500 箱 | 取整 |

### 5. 输出 — 打印并写JSON

**必须打印：**
- 基地+窑号确认
- 违规统计
- Top3计算链路
- 最终统计：营销X箱 → AI Y箱（±Z%），产能利用率P%

**写入 `/tmp/schedule-a-result.json`**

### 6. AI备注生成（通俗语言，工作人员可懂）

每个产品必须生成 `ai_remark` 字段，用通俗中文描述排产原因，避免公式和术语。

**格式模板（四种场景）：**

```
场景1：库存告急（可撑<10天）
"库存告急（实时库存Y箱），近30天日均出库Z箱，趋势{方向}，需紧急补产W箱保障供应"

场景2：库存偏低（可撑10-30天）
"库存偏低（实时库存Y箱），近30天日均出库Z箱，趋势{方向}，建议排产Z箱防止断货"

场景3：库存充足（可撑30-90天）
"库存充足（实时库存Y箱），近30天日均出库Z箱，趋势{方向}，库存健康无需紧急排产"

场景4：库存积压/无近期出库
"库存积压（实时库存Y箱），近30天日均出库量低" 或
"库存充足，近期出库量较低，建议按最低起排量或暂缓排产"
```

**关键约束：**
- **禁止写"可撑999天"等超长天数**：当日均可撑>90天时，统一写"库存积压"或"库存充足，出库量较低"
- 库存天数仅告急/偏低时展示（<30天），正常时直接说"库存充足"或"库存积压"
- 日均d30=0时（无近期出库）：标注"近期无出库"，不写天数
- 趋势用中文：上涨/下降/平稳/波动
- 定制产品需标注"定制产品，"
- 备注结尾说明排产目的（保障供应/防止断货/暂缓排产/满足最低起排）
