### 2.3 方↔箱 换算规则（来源：ERP出库单数据）

在销售出库单 `SAL_OUTSTOCK` 明细中，结合物料主数据(BD_MATERIAL)的 `F_TYTC_Qty`（每箱片数）和 `F_TYTC_Qty1`（每片面积㎡）可计算每片面积和每箱面积。

**数据来源验证：**

| ERP来源 | 字段 | 含义 |
|---------|------|------|
| 物料主数据(BD_MATERIAL) | `F_TYTC_Qty` | 每箱片数 |
| 物料主数据(BD_MATERIAL) | `F_TYTC_Qty1` | 每片面积（㎡） |

**换算公式：**
```
每片面积(㎡) = 规格宽(mm) × 规格高(mm) ÷ 1,000,000
每箱面积(㎡) = F_VRZY_Qty_jul(片/箱) × 每片面积(㎡)
日产能(箱)  = 日产能(方) ÷ 每箱面积(㎡)
```

**完整换算表（出库单已验证）：**

| 600×1200 | 3 | 0.72 | **2.16** | ✅ 出库单 F_VRZY_Qty_jul=3 |
| 750×1500 | 2 | 1.125 | **2.25** | ✅ 出库单 F_VRZY_Qty_jul=2 |
| 800×800 | 3 | 0.64 | **1.92** | ✅ 出库单 F_VRZY_Qty_jul=3 |

### 3.1 规格-窑炉匹配校验

```

例外：无。规格必须严格匹配。
输出：标记"规格不匹配"的产品

### 3.2 产能超限校验

```
每条窑的计划排产总量 ≤ 窑炉日产能(箱) × 排产周期(天)
如果超限 → 标记"产能超限"，列出超出数量和百分比
```

### 3.3 最低起排量校验

```
规则：
  标准产品：单个品种排产数 ≥ 1500箱
  定制产品：单个品种排产数 ≥ 1500箱
  新品首排：单个品种排产数 ≥ 3000箱（备注含"新品"）
  
例外：
  • 库存极高的产品（库存 > 日均出库×60天）→ 建议少排或取消
  • 备注含"取消排产" → 跳过

校验结果：
  ✓ 通过（≥最低起排量）
  ⚠ 低于最低起排量，建议调整到 XX 箱
  ⛔ 定制/新品不满足最低起排量（需人工确认）
```

### 3.4 焕白(-HB)双库存检查

```
规则：
  如果品牌+规格已经切换到焕白阶段：
    • 检查普通库存 → 标记"旧库存待消化量"
    • 检查焕白库存 → 标记"焕白当前库存"
    • 排产建议：只排-HB号，同时提示旧库存消化进度

切换时间节点（从排产表中确认）：
  800×800 → 2026年4月25日起全面-HB
  600×1200 → 2026年5月7日起全面-HB
  750×1500 → 6月13日起全面-HB
  400×800 → 6月28日起全面-HB（部分产品）

## 四、阶段3：智能优化建议

### 4.1 建议排产数再计算（核心优化）

**当前人工做法：**
```
看上月销量 + 看本周期销量 → 凭经验定个排产数
```

**智能计算公式：**

```
建议排产数 = MAX(最低起排量, ROUNDUP(
    下周期预测需求量  - 当前库存  + 安全库存
  , 排产精度))
```

**其中：**
```
下周期预测需求量 = W₁ × 近30天日均出库 × 周期天数
                  + W₂ × 近90天日均出库 × 周期天数
                  + W₃ × 去年同月日均出库 × 周期天数
(W₁=0.5, W₂=0.3, W₃=0.2，权重可调)

安全库存 = 近30天日均出库 × 安全库存天数(默认7,旺季5,淡季10)
```

**举例计算：**

假设产品 JL48800（400×800，3号窑）：
- 当前库存：669箱
- 近30天日均出库：24043÷30 ≈ 801箱/天
- 近90天日均出库：(24043+28505×2)÷90 ≈ 537箱/天
- 周期：7天
- 安全库存：801×7 = 5607箱

```
预测需求 = 0.5×801×7 + 0.3×537×7 + 0.2×去年同期×7
         ≈ 2804 + 1128 + 0 = 3932 箱
  
建议排产数 = MAX(1500, CEILING(3932-669+5607)) 
           = 8870 箱
```

对比营销计划表的 5000箱，智能体建议更多——因为该产品近30天销量暴增（28505），但库存很低（669）。

> ⚠️ **重要：** 建议排产数 ≠ 最终排产数。最终排产需结合窑炉产能分配（各产品加总不能超窑炉产能），是一个多产品全局优化问题。

### 4.2 销量异常标记（三种类型）

| 异常类型 | 检测逻辑 | 标记 | 处理建议 |
|---------|---------|------|---------|
| **突发爆款** | 近7天日均 ÷ 近90天日均 > 1.5 | 🔥 销量激增 | 提高排产优先级，检查库存是否够 |
| **断崖下跌** | 近30天日均 ÷ 近90天日均 < 0.5 | 📉 销量骤减 | 谨慎排产，参考历史低点 |
| **滞销预警** | 库存 ÷ 日均出库 > 60天 | ⛔ 库存积压 | 建议取消本周期排产，优先消化库存 |
| **库存告急** | 库存 ÷ 日均出库 < 3天 | 🚨 库存告急 | 插队优先排产，建议加急 |

### 4.3 加急/优先级量化评分

当前排产表中有"加急""优先做""已申请插排"等备注，但没有量化标准。

**量化模型：**

```
优先级评分 = 0.4 × 库存紧迫度 + 0.3 × 客户等级 + 0.2 × 销量趋势 + 0.1 × 特殊标记

库存紧迫度 = 1 / (当前库存 ÷ 日均出库 + 1)  → 0~1分
客户等级   = VIP客户/定制客户=1, 普通客户=0.5
销量趋势   = (近30天日均 ÷ 近90天日均) → 归一化
特殊标记   = 加急=1, 插排=1, 定制=0.5, 普通=0
```

**使用方式：** 排产建议按优先级评分从高到低排序。在同一条窑产能有限时，优先保障高评分产品。

### 4.4 淡季策略提醒（6/7/8月）

```
规则：
  IF 当前月份 IN (6, 7, 8) THEN
    对每个产品：
      ① 计算"销量占比" = 该产品近3个月销量 ÷ 所有同类产品总销量
      ② 标记销量占比 < 5%的产品
      ③ 提示："淡季建议优先排Top N产品，以下产品可考虑暂缓排产"
      （N = 窑炉总产能 ÷ 最低起排量 × 0.8，即能排的品种数量上限）
```

### 4.5 定制产品识别与规则排除

从Excel备注列自动解析：
- 含"定制"或客户名称（如具体业务员姓名、分公司名）→ 标记为定制
- 含"底标"（如代工品牌名）→ 标记为非自有品牌

定制产品排产规则：
- 不参与销量趋势分析（没有历史数据可比）
- 排产数量直接采用营销计划表的建议数
- 不受淡季策略约束

## 七、理论依据与模型校验方案

### 7.1 各模块的理论来源

| 模块 | 理论模型 | 文献来源 | 成熟度 | 改进方向 |
|------|---------|---------|-------|---------|
| 建议排产数 | **订货点模型（Reorder Point, ROP）** | Harris (1913) EOQ; Silver-Meal 启发式 | ⭐⭐⭐ | 补充批量约束（生产批量不能拆分） |
| 预测需求 | **加权移动平均（WMA）** | Makridakis《Forecasting: Methods and Applications》 | ⭐⭐ | → 指数平滑 / Holt-Winters / ARIMA |
| 安全库存 | **简化版安全库存** | 经典库存理论 | ⭐⭐ | → σ-based 标准差法 |
| 优先级评分 | **多准则决策加权和法（WSM）** | Saaty (1980) AHP | ⭐⭐ | → AHP 成对比较 / 熵权法 |
| 产能约束 | **多产品排产优化** | 作业调度理论（Job Shop Scheduling） | ⭐ | 初期硬约束校验，后续引入启发式算法 |
| 异常标记 | **阈值规则** | 统计过程控制（SPC） | ⭐ | → 控制图（Control Chart） |

#### 7.1.1 订货点模型（建议排产数）

经典公式：
```
ROP = d × LT    （基本型：不考虑安全库存）
ROP = d × LT + SS  （考虑安全库存）
```
其中 d=日均需求, LT=提前期, SS=安全库存。

对应到排产场景：
```
建议排产数 = 预测需求(排产周期内) + 安全库存 - 当前库存
```

约束条件：排产数必须为整数、满足最低起排量、且不超过窑炉可用产能。

#### 7.1.2 加权移动平均（预测需求）

固定权重 WMA：
```
Ŷ_{t+1} = W₁ × MA_30 + W₂ × MA_90 + W₃ × YoY
```

当前权重 W₁=0.5, W₂=0.3, W₃=0.2 为初始设定，含义：
- 近30天占50%——捕捉最新趋势
- 近90天占30%——平滑短期波动
- 去年同比占20%——季节因子

**进阶替代方案（优先级排序）：**

| 方法 | 适用场景 | 数据要求 |
|------|---------|---------|
| 简单指数平滑（SES） | 无明显趋势和季节性 | ≥30个时间点 |
| **Holt-Winters（推荐）** | 有趋势+季节性 | ≥2个完整年度 |
| ARIMA | 复杂时间模式 | ≥50个时间点 |
| Prophet (Meta) | 含节假日效应 | ≥1年 |

> **推荐路径：** 先跑WMA作为基准，拿到足够历史数据后切换 Holt-Winters。

#### 7.1.3 标准差法安全库存

当前简化版：
```
SS = d_avg × K
```

标准统计版：
```
SS = Z_α × σ_d × √(LT)
```

其中：
- Z_α = 服务水平系数（90%→1.28, 95%→1.65, 99%→2.33）
- σ_d = 需求标准差（反映波动性）
- LT = 提前期（排产周期，当前7天）

**为什么标准差法更好：**
假设两个产品A和B，近30天日均都≈500箱：
- A：每天稳定在480~520箱（σ_d=15）
- B：一天50箱，一天950箱（σ_d=300）

简化版给A和B相同的安全库存，但B的需求波动是A的20倍，断货风险完全不同。标准差法能准确捕捉这种差异。

#### 7.1.4 AHP确定优先级权重

当前权重（0.4, 0.3, 0.2, 0.1）为经验设定。规范做法应使用 **AHP成对比较矩阵**：

需与排产业务员一起填写以下矩阵：

|  | 库存紧迫度 | 客户等级 | 销量趋势 | 特殊标记 |
|--|----------|---------|---------|---------|
| 库存紧迫度 | 1 | ? | ? | ? |
| 客户等级 | | 1 | ? | ? |
| 销量趋势 | | | 1 | ? |
| 特殊标记 | | | | 1 |

评分标度：1=同等重要, 3=稍重要, 5=明显重要, 7=强烈重要, 9=极端重要

计算特征向量 → 归一化 → 得到最终权重。同时计算一致性比率（CR<0.1可接受）。

### 7.2 模型参数校验方案

核心思路：**用历史数据模拟排产，对比"模型推荐"和"人工实际排产"，评估差异合理性。**

#### 校验流程

```
Step 1: 选取历史数据
  → 选择2026年3月~7月的5次排产计划作为测试集
  → 对应时段的ERP库存数据和出库数据

Step 2: 回测执行
  → 将测试数据的"营销计划表"作为输入
  → 用模型生成排产建议
  → 对比当时人工排产的实际情况

Step 3: 评估指标
  → 预测准确率: MAPE = (1/n) × Σ|预测-实际|/实际
  → 差异合理性: 模型建议与实际差异<20%=绿, 20~50%=黄, >50%=红
  → 库存覆盖率: 模型建议排产后，下周期库存是否覆盖需求
  → 产能利用率: 模型建议是否更充分利用窑炉产能

Step 4: 参数调优
  → 网格搜索（Grid Search）不同权重组合
  → 找到MAPE最小的权重配置
```

#### 代码框架

```python
# 伪代码：参数校验
def backtest_one_period(plan_date, weight_combo):
    """
    plan_date: 排产日期（如 2026-04-02）
    weight_combo: (W1, W2, W3) 权重组合
    返回: MAPE, 产能利用率, 库存覆盖率
    """
    # 1. 读取对应时期的营销计划表
    plan_data = read_marketing_plan(plan_date)
    
    # 2. 查询该日期之前的实际出库数据（模拟"当时可见"的数据）
    sales_7d = query_sales_history(plan_date, days=7)
    sales_30d = query_sales_history(plan_date, days=30)
    sales_90d = query_sales_history(plan_date, days=90)
    inventory = query_inventory(plan_date)
    
    # 3. 用给定权重计算建议排产数
    suggestions = []
    for product in plan_data:
        predicted = predict_demand(sales_30d, sales_90d, weight_combo)
        suggested = max(1500, predicted - inventory + safety_stock)
        suggestions.append(suggested)
    
    # 4. 与人工实际排产对比
    actual = read_actual_production(plan_date)
    mape = mean_abs_percent_error(suggestions, actual)
    
    return mape


# 网格搜索最优权重
best_mape = float('inf')
best_weights = None
for w1 in [0.3, 0.4, 0.5, 0.6]:
    for w2 in [0.2, 0.3, 0.4]:
        for w3 in [0.1, 0.2, 0.3]:
            if w1 + w2 + w3 != 1.0:
                continue
            mape = backtest_one_period('2026-04-02', (w1, w2, w3))
            if mape < best_mape:
                best_mape = mape
                best_weights = (w1, w2, w3)

print(f"最优权重: W1={best_weights[0]}, W2={best_weights[1]}, W3={best_weights[2]}")
print(f"最小MAPE: {best_mape:.2%}")
```
