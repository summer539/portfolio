# 智能排产处理流程

> ⚠️ **已废弃（2026-07-30）**：本文档中的列布局（19列/25列）、字段名（生产数量/日均30d）等已更新。
> 最新格式请参考：`references/output-format-design.md` 和 `references/rules.md`。

## 输入

1. **营销排产计划表**（Excel文件）：包含品牌、编号、规格、工艺、上月/本月销量、库存、排产数量、备注（含MAT和JL编码产品）
2. **排产日期**：从文件名或用户提示中提取（如"7月25日"）

## 四阶段处理流水线

### 阶段1：数据解析

1. 用 xlrd 或 openpyxl 读取 Excel 文件
2. 解析品牌区域结构：
   - 品牌行：`col0=品牌名, col1=首个编号` — 标记为新品牌
   - 数据行：`col0='', col1=编号` — 归属当前品牌
   - 小计行：`col0='小计'` — 品牌结束
   - 总计行：`col0='总计'` — 全部结束
3. 提取字段：品牌、生产编号、规格、工艺、上月销量、本月销量、库存、排产数量、备注
4. 自动识别：定制产品（备注含"定制"）、新品（备注含"新品"）
5. **基地识别**：编码前缀 `MAT%`→某陶瓷企业 / `b%`→B 基地
6. 规格→窑炉匹配：600×1200→2号窑（某陶瓷企业）

### 阶段2：规则校核

1. **规格-窑炉匹配**：校验规格与所分配的窑炉一致
2. **产能超限**：ΣAI建议 / (日产能(箱)×7) ≤ 100%（分基地独立计算）
3. **最低起排量**：检查每项是否满足规则
4. **焕白双库存**：-HB后缀产品同时查普通+焕白库存

### 阶段3：智能优化（核心计算）

两个基地分别独立运行 V6 算法，参数如下：
- 某陶瓷企业：查某陶瓷企业库存+销量，产能用某陶瓷企业对应窑炉参数
- B 基地：查B 基地库存+销量，产能用B 基地窑参数(31,250箱/d)

### 阶段4：Excel输出（3 Sheet）

#### Sheet 1: 某陶瓷企业·排产计划（19列）

与原有格式完全一致，标题行 `某陶瓷企业生产基地 · {规格} · 排产计划`

#### Sheet 2: B 基地·排产计划（19列）

格式同 Sheet1，标题行 `B 基地生产基地 · {规格} · 排产计划`

> 仅400×800有B 基地产品，其他规格标注「B 基地无此规格排产」

#### Sheet 3: 总结报告（25列）

新增B列「基地」，合计行分三层：某陶瓷企业小计 → B 基地小计 → 总计

## 输出结构

**标题行：** `某陶瓷企业生产基地 · {规格} · 排产计划`

**核心原则：全表纯白底无填充色，唯一例外是AI差异黄色标记。**

**列宽（19列）：** A=12, B=10, C=22, D=12, E=10, F=10, G=10, H=10, I=14, J=14, K=23, L=55, M=10, N=10, O=10, P=10, Q=10, R=10, S=40

- ✅ 除此以外，**全表纯白底，无任何底色**——包括品牌行、合计行、总计行、定制产品行全部不加底色

### AI备注格式规范

备注必须包含完整推理链路，格式为3-4个分号分隔的部分：

**普通产品（有销售数据）：**
```
销量{趋势}，{上月}月{val1}→{本月}月{val2}箱（{变化率}%）；日均{val}箱；库存{val}箱（够{N}天）；{AI推理}
```
AI推理部分选项：
- `计算需{N}箱＜营销{val}箱，建议加至{val}箱`（ai > plan）
- `计算需{N}箱，与营销一致`（ai == plan）
- `库存覆盖需求，计算需{N}箱，参考营销保留{val}箱`（库存充足，ai < plan）
- `销量下滑+库存充足，计算需{N}箱，建议缩减至{val}箱`（趋势↓+库存多）
- `库存严重积压，计算仅需{N}箱，建议缩减至{val}箱`（库存>60天）

**新品/无销售数据：**
```
新品首排（最低3000箱，营销{val}箱）无历史数据，建议投产{val}箱
```

**定制产品附加：** 末尾追加"；定制产品"
