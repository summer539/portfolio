## 二、关键约束规则

### 2.1 窑炉产能（核心硬件约束）

| 窑号 | 规格 | 日产能（方） |
|------|------|-------------|
| 1号窑 | 750×1500 | 26,000 方 |
| 2号窑 | 600×1200 | 38,000 方 |
| 3号窑 | 400×800 | 38,000 方 |
| 5号窑 | 800×800 | 26,000 方 |

**注意：** 窑号从1、2、3跳到5，无4号窑。

### 2.2 排产约束

| 规则 | 说明 |
|------|------|
| **最低起排量** | 所有产品≥1500箱/窑（含标准品/定制），新品≥3000箱 |
| **新品首排** | 一般3000箱 |
| **排产周期** | 7天一个周期，不固定，根据行情调整 |
| **提前期** | 营销中心提前3-5天给计划表 |
| **淡季策略** | 6、7、8月淡季，行情不好时只排销量前几的产品 |
| **参考维度** | 上月销量 + 上周期销量 对比趋势 |
| **特殊处理** | 定制产品不受常规规则约束 |

### 2.3 焕白（-HB）产品特殊规则

- 编码带 `-HB` 后缀表示焕白产品（底胚升级，花色一致）
- 可能出现 **同花色两套库存**：普通库存 + 焕白库存
- 旧产品未售完的剩余在普通库存
- 排产需 **同时参考两者**

### 2.4 数据范围限定

| 数据类型 | 范围 | 说明 |
|---------|------|------|
| **库存** | 某陶瓷企业生产基地 + B 基地生产基地 | 只看成品仓 |
| **销售** | 同上 | 查销售出库数据 |

## 四、排产助手能力分析

### 当前可直接实现的能力

1. **库存查询助手**
   - 查询指定物料在成品仓的即时库存
   - 限定范围：A 基地 + B 基地
   - 区分普通库存和焕白（-HB）库存

2. **销量趋势分析**
   - 基于出库单统计近几周/近一月销量
   - 按品牌、物料、规格维度汇总
   - 支撑「上月 vs 上周期」对比

3. **排产建议计算**
   - 输入：营销计划表（Excel导入）
   - 约束：窑炉产能、最低起排量、库存情况
   - 输出：各窑排产建议方案

### 需要人工补充的知识

- 窑炉产能数据（需录入到系统）
- 行情/季节性判断规则
- 新品/定制品的标识规则
- 营销排产计划表模板（Excel格式）
