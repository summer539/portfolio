### 4.3 排产部门实际执行特点

**排产数量 vs 生产数量的差异：**
- 排产部门有时会调整数量（多于或少于营销中心计划）
- 例如 1号窑第一批 金博达：排产4000→生产数量留空，但跟踪表显示入仓2273箱
- 存在"已排未出货"字段（如 好运来 HL8K011：库存4717，排产2000，已排未出货有数据）

**上线跟踪表揭示的实际产能：**
- 每个品种的实际入仓数量可以精确追踪
- 入仓数量 < 排产数量 是常态（部分产品完成度低于100%）
- 部分产品标注"待砖形反弹回来"等工艺问题

## 五、智能排产需处理的核心映射

```
营销中心Excel
  ↓ 读取
品牌 + 物料编号 + 规格 + 工艺 + 建议排产数量 + 库存参考 + 备注
  ↓
智能体处理
  ① 校验：该规格是否匹配对应窑炉
  ② 校核：该批次总量是否超出窑炉日产能
  ③ 参考：当前库存水位（ERP数据）
  ④ 规则：最低起排量、焕白策略、定制处理
  ↓
输出
排产建议方案（按窑/按品牌/按产品编号）
```
