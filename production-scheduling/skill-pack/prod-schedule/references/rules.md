## 五、V6 多时间维度耦合缺口裁决（核心算法）

### 5.1 设计理念

**7天算缺口底线 → 30天验趋势真伪 → 90天设边界安全阀**。三层耦合，各司其职。

### 5.2 三日均计算

```
d7  = s_cycle / 7     ← 近7天日均（即时需求）
d30 = s_30d  / 30     ← 近30天日均（中期均值）
d90 = s_90d  / 90     ← 近90天日均（长期基线）
```

### 5.3 趋势判定（三级梯度法）

| 状态 | 条件 | 图标 |
|------|------|:--:|
| 加速上涨 | d7 > d30 > d90×1.2 | 🔥 |
| 回暖上涨 | d7 > d30 ≈ d90（偏差<20%） | 📈 |
| 平稳 | d7 ≈ d30 ≈ d90 | ➡️ |
| 降温 | d7 < d30×0.7 且 d30≈d90 | 📉 |
| 持续衰减 | d7 < d30 < d90 | ⬇️ |
| 脉冲波动 | d7 > d30×2.0 或 d7 < d30×0.3 | ⚡ |

### 5.4 双缺口取大

```
gap_7        = max(0, s_cycle − inventory)
d_weighted   = 0.5×d7 + 0.3×d30 + 0.2×d90
gap_weighted = max(0, d_weighted × 7 − inventory)
effective_gap = max(gap_7, gap_weighted)
```

脉冲波动时：屏蔽7天异常数据，以30天为准。

### 5.5 趋势加成

```
effective_gap > 0:
  加速上涨:  max(base_P, d_weighted×10−inventory)  ← 多备约3天
  回暖上涨:  max(base_P, d_weighted×8−inventory)   ← 多备约1天
  平稳:      不变
  降温/衰减: 以30天×7为准，不低于 MIN_BATCH
  脉冲波动:  以30天×7为准

effective_gap = 0:
  M ≤ s_cycle×3 → 批准
  M > s_cycle×3 趋势好→批准 / 趋势差→人工确认
  衰减/降温 → 压至 MIN_BATCH
```

### 5.6 安全阀 + 硬约束

```
90天上限:  P ≤ d90 × 60天
上穿校正:  d30 > d90 且 P偏低 → 上修
产能上限:  P ≤ 日产能(箱)（满产）
批次取整:  round(P/500)×500
```

### 5.7 参数依据

| 参数 | 值 | 依据 |
|:--|:--:|:--|
| 加权日均权重 | 0.5/0.3/0.2 | 7天敏感>30天稳定>90天基线 |
| 加速备货系数 | ×10天 | 约=加权日均×7+3天缓冲 |
| 回暖备货系数 | ×8天 | 约=加权日均×7+1天缓冲 |
| 90天上限 | ×60天 | 不超过两月备货量 |
| M偏高阈值 | M > s_cycle×3 | 回测数据自然分界 |
| 脉冲判定 | 2.0× / 0.3× | 7天偏离30天超2倍或不足1/3 |

## 六、风险标记规则

| 条件 | 标记 | 含义 |
|------|------|------|
| 库存=0 且 日均>5 | 🚨告急 | 零库存高风险 |
| 库存天数<3 且 日均>0 | 🚨告急 | 库存极低 |
| 库存天数<10 且 日均>0 | 🔥偏低 | 库存偏低 |
| 库存天数>60 且 库存>500 | ⛔积压 | 库存积压 |
| 趋势⬇️持续衰减 且 日均>5 | 📉骤降 | 销量断崖 |
| 趋势🔥加速上涨 且 日均>20 | 📈激增 | 突然放量 |

> **库存天数上限**：当日均出库=0（无近期销量）时，库存天数记为 `None`，风险标记为 ⛔积压（有库存）或无标记（库存=0）。**禁止展示"可撑999天"等超长天数。**

## 七、优先级评分

```
优先级 = 0.4 × 库存紧迫度 + 0.3 × 客户等级 + 0.2 × 销量趋势 + 0.1 × 特殊标记

库存紧迫度 = 1 / (库存天数 + 1)
客户等级 = 定制产品=1.0, 普通=0.5
销量趋势 = min(2.0, d30/max(d90,1)) / 2.0
特殊标记 = 定制=0.5, 新品=0.5, 普通=0
```

## 八、产能校核

```
排产总需求量 / (窑炉日产能(箱) × 7) ≤ 100%
超限时标记"产能超限"并列出超出数量
```
