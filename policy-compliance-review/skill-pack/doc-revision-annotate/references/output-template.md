# 修改清单输出模板

> 定义 doc-revision-annotate 在对话中输出的修改清单格式与规范。

---

## 一、输出时机

每次生成文件时，**同时在对话中自动输出修改清单**，与文件一同交付。

---

## 二、修改清单模板（对话中展示）

```
📝 修订批注完成

文件名称：xxx.docx
输出文件：xxx-修订批注版.docx
作者署名：文档修订批注助手

━━━ 修改统计 ━━━
✅ 修订：X 处（替换 X / 删除 X / 插入 X）
💬 批注：X 条
⚠️ 未执行：X 处（未找到目标文本等）

━━━ 修改清单 ━━━

| 序号 | 位置 | 操作 | 原文 | 修改后 | 批注 |
|------|------|------|------|--------|------|
| 1 | 段落5 | 替换 | 经师 | 经济师 | 【修改建议】原文"经师"，建议改为"经济师" |
| 2 | 表1.R4.C5 | 替换 | 副司 | 副司长 | 【修改建议】原文"副司"，建议改为"副司长" |
| 3 | 表2.R2.C1 | 删除 | 冗余文字 | — | 建议删除冗余表述 |
| 4 | 段落8 | 插入 | （在"附件："后） | 附件1清单 | 建议补充附件引用 |
| 5 | 表3.R5.C2 | 仅批注 | — | — | 此处信息请确认 |
```

**位置表述规范：**
- 正文段落：`段落N`（0 起始索引，与脚本 para_index 一致）
- 表格单元格：`表N.R行.C列`（N/行/列均从 1 起始显示，脚本内部为 0 起始）

**操作类型：**
| 操作 | 含义 |
|------|------|
| 替换 | 原文删除 + 新文插入（Track Changes 修订） |
| 删除 | 仅删除原文（修订标记） |
| 插入 | 在指定锚点文本后插入新文（修订标记） |
| 仅批注 | 不修改原文，仅添加批注 |

---

## 三、失败项说明

未执行的条目必须列出原因：

```
━━━ 未执行项 ━━━

| 序号 | 位置 | 目标文本 | 失败原因 |
|------|------|----------|----------|
| 3 | 表2.R2.C1 | "旧表述" | 文档中未找到该文本，已跳过 |
```

常见失败原因：
- 文档中未找到目标文本（可能已被修改或存在空格/换行差异）
- 段落索引/表格坐标越界
- 缺少必要参数（如 insert 缺 anchor、批注缺 comment）

## 四、批注格式规范

### 4.1 默认格式

```
【修改建议】原文"xxx"，建议改为"yyy"
```

**示例：**
- `【修改建议】原文"经师"，建议改为"经济师"`
- `【修改建议】原文"示例留服务中心"，建议改为"示例留学服务中心"`
- `【修改建议】建议在第3段后补充项目联系人信息`
- `【待确认】原文"1380013800"，疑似缺位，请核实`

### 4.2 规则

1. **用户指定格式优先：** 用户提供自定义批注格式或直接给出批注文本时，**原样写入**，不套用默认格式
2. **用户给出修改意见（自然语言）时：** 智能体按默认格式整理为 `【修改建议】原文"xxx"，建议改为"yyy"`
3. **Word 批注纯文本：** 任何情况下 Word 批注不得包含 emoji/颜色图标
4. **简洁明确：** 批注只描述修改本身，不包含规则编号、位置引用等元信息

### 4.3 建议类批注（无原文可引时）

```
【修改建议】建议"xxx"
【补充建议】建议补充"xxx"
【待确认】"xxx"，请核实
【提示】"xxx"
```

## 五、多文件输出模板

同时处理多个文件时，按文件分别输出清单：

```
📝 修订批注完成（共 N 个文件）

━━━ 1. xxx.docx ━━━
（修改统计 + 修改清单，格式同上）

━━━ 2. yyy.docx ━━━
（修改统计 + 修改清单，格式同上）
```

---

## 六、与脚本的对应关系

| 输出清单字段 | 脚本 JSON 字段 | 说明 |
|--------------|----------------|------|
| 位置（段落N） | `scope: "para"`, `para_index: N` | 0 起始索引 |
| 位置（表N.R.C） | `scope: "cell"`, `table/row/cell` | 0 起始索引 |
| 操作：替换 | `action: "replace"`, `old`, `new` | — |
| 操作：删除 | `action: "delete"`, `old` | — |
| 操作：插入 | `action: "insert"`, `anchor`, `new` | 在 anchor 后插入 |
| 操作：仅批注 | `comment_only: true`, `comment` | Word 通用 |
| 批注内容 | `comment` | 用户指定则原样写入 |
| 作者署名 | `author` | 默认"文档修订批注助手" |
