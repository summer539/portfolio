# 制度快速审核规则说明

## 1. 默认目标

快速审核用于在一次执行中完成：制度类型识别、组织范围识别、必备条款检查、章节主题检查、命名审核和关键格式审核。默认不进行法规检索、跨制度比对和逐页渲染。

## 2. 默认执行规则

### 完整性

- 根据制度名称和正文特征只选择一个主类型规则集；
- 员工手册执行16项劳动用工条款和13项专门章节主题；
- 公司章程执行14项核心条款和12项专门章节主题；
- 治理类制度执行议事决策10项必备条款和9项章节主题；
- 采购代理机构制度执行8项采购代理专门规则；
- 其他已配置类型执行对应专门规则；
- 未配置类型只执行通用规则，并提示补充专门清单；
- 所有被选规则必须全部遍历，JSON记录 selected_rules、executed_rules 和 coverage_rate。

### 规范性

命名审核以 DOCX 正文正式标题为准；文件名仅用于标题载体一致性比对，不参与层级词和名称内容判断。

默认审核：名称层级、名称与内容匹配、内部自称、正式组织名称、标题和正文字体字号、章标题居中、正文行距、A4页面、3.17厘米左右页边距、页码和编号体系。

默认跳过：正文对齐、正文首行缩进、法规有效性、跨制度一致性和视觉渲染。

## 3. 组织架构

组织数据统一维护在 `references/organization_structure.json`。脚本会将兼任名称、直属单位、下属中心、分公司和子公司映射到正式组织名称，并在审核结果中输出 organization_scope 和 matched_organizations。

未纳入架构数据的下层组织不会直接判错，避免对省分内部部门、项目组、实验室和临时机构产生误报。

## 4. 一键执行

```powershell
python scripts/quick_audit.py "制度文件.docx"
```

指定输出目录：

```powershell
python scripts/quick_audit.py "制度文件.docx" --output-dir "审核输出\\项目名称"
```

输出包括：

- `制度快速审核报告.md`
- `制度完整性和规范性审核报告.md`
- `制度快速审核汇总.json`
- `completeness/` 完整性明细
- `normative/` 规范性明细

标准输出仅作为进度信息，系统对接应读取输出目录中的 JSON 文件。
