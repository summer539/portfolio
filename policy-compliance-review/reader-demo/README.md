# 制度审核查看器 v3

# 简介
基于 Python + WPS/Word COM 的制度文档审核可视化阅读器。支持：
- 加载 .docx 文件，自动通过 WPS 渲染为 PDF 并在浏览器展示
- 右侧显示合规审核问题卡片（含问题描述、修订依据、修订建议）
- 修订 Tab 支持逐条接受/拒绝
- 对比视图：左侧显示修订前（删除文字带红色删除线），右侧显示修订后（新增文字显示绿色）
- 右侧 diff Tab 按全部/新增/删除/修改分类，内容来自批注第四段【修订性质】

# 环境要求
- **Windows 系统**（依赖 WPS 或 Microsoft Word COM 组件渲染 PDF）
- **Python 3.10+**（推荐 3.13），需加入 PATH
- **WPS Office** 或 **Microsoft Word**（已安装，能正常打开 .docx）
- 网络可访问（首次加载 pdf.js CDN，之后离线可用）

# 部署步骤

## 1. 解压
将 v3.zip 解压到任意目录，例如 D:\\docx-viewer。

## 2. 安装依赖
打开命令行（CMD 或 PowerShell），进入解压目录，运行：
`
pip install -r requirements.txt
`
或者直接双击 start.bat，它会自动安装依赖并启动服务。

## 3. 启动服务

### 方式一：双击 start.bat
双击 start.bat，脚本会自动检查 Python、安装依赖、启动服务。
默认端口 5173，也可在命令行传入自定义端口：
`
start.bat 8080
`

### 方式二：命令行手动启动
`
python server.py
`
默认端口 5173，也可指定端口：
`
python server.py 8080
`

启动后终端会显示访问地址。

# 使用方法

## 单文件视图
1. 浏览器打开 http://127.0.0.1:5173/
2. 点击「打开文件」按钮，选择 .docx 文件（含修订和批注）
3. 等待 WPS 渲染完成，左侧显示 PDF
4. 右侧两个 Tab：
- **合规审核**：每条问题卡片显示问题描述（修改一句话）、修订依据、修订建议，底部有接受/拒绝按钮
- **修订**：逐条显示修订标记（新增/删除/移动），可逐条接受或拒绝
5. 点击任意卡片可定位到 PDF 对应位置（📌 标记）
6. 接受/拒绝修订后，PDF 会自动重新渲染

## 对比视图
1. 加载文件后点击「进入对比视图」
2. 左侧：修订前状态（删除的文字保留并显示红色删除线，新增文字不显示）
3. 中间：修订后状态（新增文字显示绿色，删除文字不显示）
4. 右侧 Tab 按全部/新增/删除/修改分类，内容来自批注第四段【修订性质】
5. 勾选「同步滚动」可双栏联动，点击卡片取消同步并定位到对应位置
6. 点击「返回编辑」回到单文件视图

# 常见问题

**Q: 启动报错找不到 Python？**
A: 安装 Python 3.10+，安装时勾选「Add Python to PATH」。下载：https://www.python.org/downloads/

**Q: 渲染 PDF 报错？**
A: 确保已安装 WPS Office 或 Microsoft Word，且能正常打开 .docx 文件。服务通过 COM 组件调用 WPS/Word 完成 PDF 渲染。

**Q: 其他电脑如何访问？**
A: 服务监听 0.0.0.0，局域网内其他电脑可通过 http://本机IP:5173/ 访问。需在防火墙放行 5173 端口。

**Q: 页面打开是空白的？**
A: 等待 WPS 渲染完成（右下角有加载动画），首次渲染可能需要 10-30 秒。

**Q: 批注格式要求？**
A: 批注文本需包含四段式结构：【修改/删除/新增】+【修订依据】+【修订建议】+【修订性质】。第四段格式：修订性质\n{原始}：旧内容{修改}：新内容 或 删除\n{删除}：内容 或 新增\n{新增}：内容。
